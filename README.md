# EcoSolar — اپلیکیشن اندروید (Flutter)

اپ کاربر پلتفرم EcoSolar مطابق سند معماری (سطح ۱، SCR-C-01 تا SCR-C-63)، راست‌به‌چپ، اعداد فارسی و تاریخ شمسی.

## ساخت APK

روش ۱ (بدون نصب چیزی): پوشه را در یک مخزن GitHub قرار دهید. گردش‌کار `.github/workflows/android.yml` خودکار APK می‌سازد و در بخش Actions با نام `ecosolar-apk` قابل دانلود است.

روش ۲ (روی سیستم خودتان، Flutter 3.24 یا جدیدتر):

```bash
cd ecosolar_app
flutter create . --platforms android --org ir.ecosolar --project-name ecosolar
flutter pub get
flutter run            # اجرا روی گوشی یا شبیه‌ساز
flutter build apk --release
```

برای نمایش فونت Vazirmatn، مجوز INTERNET لازم است (گردش‌کار آن را اضافه می‌کند؛ در روش ۲ در `android/app/src/main/AndroidManifest.xml` اضافه کنید).

## ورود نمایشی
هر شماره موبایل معتبر (09xxxxxxxxx) و کد یکبارمصرف `123456`. همین کد برای تأییدهای دومرحله‌ای (امضای قرارداد، برداشت، پیش‌پرداخت) است.

## ساختار
- `lib/core` — تم طراحی، اعداد فارسی، تقویم شمسی، اعتبارسنجی کد ملی و شبا (mod-97)
- `lib/widgets` — اجزای مشترک (CMP-01 تا CMP-24): کارت، برچسب وضعیت، سناریو، نمودارها، گیج پوشش قسط، مرحله‌نما، پنل «چرا؟»، تأیید دومرحله‌ای، شمارش معکوس
- `lib/data` — مدل‌ها، قرارداد API مطابق سند (`api.dart`) و وضعیت برنامه با داده نمایشی (`store.dart`)
- `lib/screens` — صفحه‌ها، مسیرها در `lib/routes.dart`

## اتصال به بک‌اند
اپ الان با داده نمایشی در حافظه کار می‌کند. برای نسخه عملیاتی، کلاس `Api` را با HTTP پیاده‌سازی کنید و تغییرات `AppState` را به آن وصل کنید. اتصال واقعی به مهرسان، شرکت توزیع، بانک و اینورتر به بک‌اند و قرارداد با این نهادها نیاز دارد.
